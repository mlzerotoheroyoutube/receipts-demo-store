# receipts-demo-store

A tiny shopping cart used to demo [Receipts](https://github.com/mlzerotoheroyoutube/receipts):
AI coding agents open PRs against it, and Receipts checks whether they really fix the issues.
The rules every change must follow are in the docstring of `store/cart.py`.

```bash
python -m pytest -q
```

Built at the AIE Code Summit Hackathon, Nov 7 2026. MIT licensed.
